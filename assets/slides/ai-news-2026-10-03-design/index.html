한 주의 흐름부터 보겠습니다. 9월 29일(미국) OpenAI DevDay에서 GPT-6.1 Sol이 나왔습니다. 9월 22일에 나온 GPT-6 Sol의 후속입니다. 같은 날 GitHub Copilot에서도 정식 제공을 시작했고, 늘 켜져 있는 개인 에이전트 dots도 함께 나왔습니다.

9월 30일(미국)에는 Google이 Gemini 4 Argon을 발표했습니다. 같은 날 GitHub Copilot에 HydraFusion이 리서치 프리뷰로 들어왔습니다. 여러 모델을 Single, Cascade, Critique 세 방식 중 하나로 섞어 쓰는 기능입니다.

10월 1일(미국) Anthropic이 Claude Code Mods를 내놓았고, Copilot CLI와 앱은 데스크톱 앱을 직접 조작하는 컴퓨터 사용을 공개 프리뷰로 열었습니다. CLI에서는 /computer on으로 켭니다.

10월 2일 Copilot은 Claude Opus 4.7을 Opus 5.5로, Gemini 3.5·3.6 Flash를 3.8 Flash로, Kimi K2.7 Code를 K3로 바꾸라고 안내했습니다. 10월 3일 Claude Code v2.1.288은 Ctrl+C로 지운 프롬프트를 ↑로 되살리는 기능과, 권한 확인 없이 도는 설정에서 bash -c 안의 위험한 rm이 실행되던 문제 수정이 들어갔습니다.

출처: Claude 블로그 「Customize Claude Code with mods in TypeScript」03 / 07

Anthropic이 10월 1일(미국) Claude Code에 Mods를 내놓았습니다. 몇 줄짜리 TypeScript로 Claude Code의 동작과 화면을 바꾸는 확장입니다. 플러그인에 담아 나눌 수 있고, CLI와 데스크톱 앱에서 동작합니다.

Claude Code의 기본 기능 일부도 이제 mod입니다. 예를 들어 /diff는 끄거나 내가 만든 것으로 바꿀 수 있습니다.

주의할 점은 샌드박스가 없다는 것입니다. mod는 Claude Code와 같은 권한으로 내 컴퓨터에서 돌아가니, 믿을 수 있는 곳의 mod만 깔라고 안내합니다. Team·Enterprise 요금제와 관리 설정이 있는 컴퓨터에서는 sec-default라는 기본 mod가 먼저 실행돼, 사용자가 깐 mod의 위험한 동작을 막습니다.

같은 주에 원격 사용 관련 수정도 여럿 들어갔습니다. v2.1.285(9월 30일)에서 claude --desktop으로 지금 폴더를 데스크톱 앱에서 열 수 있게 됐고, v2.1.287~288(10월 2~3일)에서 Remote Control이 몇 분씩 메시지를 못 받던 문제와 Mac이 잠자기에 들어가면 세션이 멈추던 문제를 고쳤습니다.

이번 주에 나온 두 모델의 가격을 나란히 놓으면 출발점이 같습니다.

GPT-6.1 Sol의 API 가격은 입력 272K 토큰 이하 기준으로 100만 토큰당 입력 $2, 캐시 입력 $0.10, 캐시 쓰기 $2.50, 출력 $10입니다. OpenAI 변경 이력에는 「GPT-6 Astra보다 낮은 비용으로 복잡한 코딩과 전문 업무를 하는 모델」이라고 적혀 있습니다. 서브에이전트에 일을 나눠 맡기는 멀티 에이전트 기능이 베타로 들어갔고, GitHub Copilot에서는 Pro+·Max·Business·Enterprise에서 정식 제공을 시작했습니다.

Gemini 4 Argon은 도입가가 100만 토큰당 입력 $2, 출력 $10이고, 도입 기간이 끝나면 $4, $20이 됩니다. 다만 지금은 사이버 방어 담당자를 위한 Fairwind 프로그램에만 풀었고, 다음 차례인 유료 API 고객과 Google AI Ultra 구독자에게 언제 풀지는 밝히지 않았습니다. 출력 한도는 64K에서 1M 토큰으로 늘렸고, Google은 DeepSWE v1.1에서 77.9%로 최고 기록을 세웠다고 밝혔습니다. 이 성능 수치는 회사가 밝힌 것이고 독립적으로 재현한 결과가 아닙니다.

덧붙여, GPT-6.1 Astra는 출시가 취소됐다는 보도가 있었습니다. Engadget이 월스트리트저널을 인용해 전한 것이고 OpenAI 발표는 아닙니다.

과기정통부는 9월 29일 AI중심대학 18곳과 AX대학원 15곳을 출범시켰습니다. 대학 SW 교육의 틀이 바뀌는 소식이라 우리 동아리와도 가깝습니다.

AI중심대학은 신규 3곳과 SW중심대학에서 전환한 15곳입니다. 대학마다 최장 8년 동안 해마다 30억 원을 지원합니다. 참여 대학은 전교생 AI 기초교육을 의무로 하고, 전공과 AI를 잇는 융합 교과목을 새로 엽니다. 내년에는 아직 전환하지 않은 SW중심대학 38곳을 평가해 AI중심대학으로 전면 전환할 계획입니다.

비수도권 대학은 AI중심대학 18곳 중 11곳, AX대학원 15곳 중 8곳입니다. 내년 이후 새로 뽑을 때는 비수도권 비율을 70% 이상으로 늘립니다.

경북대가 18곳에 들어 있는지는 이 기사로는 확인하지 못했습니다. 질문이 나오면 그렇게 답하면 됩니다.

  • 위키독스에 무료 공개
출처: 긱뉴스 「클로드 코덱스 스킬 가이드북」 (10월 1일)07 / 07

마지막은 써 볼 만한 것입니다. 국내 개발자가 Claude Code와 Codex의 에이전트 스킬을 골라 한국어로 정리한 책을 위키독스에 무료로 공개했습니다. 긱뉴스 10월 1일 글입니다. 공개 첫 주 위키독스 주간베스트 3위(주간 조회 12,738회)에 올랐습니다.

8개 분야, 스킬 56개를 담았고, 최근 90일 안에 관리되고 MIT·Apache-2.0 라이선스인 것만 골랐습니다.

인상적인 숫자는 저자 자신의 경험입니다. 스킬을 82개 만들었는데 110일 동안 한 번이라도 쓴 것은 27개였다고 합니다. 스킬을 많이 만드는 것보다 고르는 게 어렵다는 이야기입니다.

원문에는 이 밖에도 AWS 서울 리전의 Claude, 독파모, 업스테이지 솔라 미니 4, herdr web ui 소식이 있습니다. 블로그 글에서 출처와 함께 볼 수 있습니다.
