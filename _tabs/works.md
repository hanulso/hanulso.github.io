## 2001년

- **호빵** — 14기 최희백, 15기 곽효석, 15기 서원경, 15기 박재덕

  뿌요뿌요 형식의 퍼즐 게임. Win CE 3.0용으로 만들고 서버와 PC용 게임도 만들어 PDA끼리, PDA와 PC, PC끼리 네트워크 대전이 됩니다. PDA 적외선 포트로 대전하는 기능이 있었습니다.
- **경북대학교 시간표 작성기** — 11기 선진욱, 15기 조혜정, 15기 백종복

  학교 홈페이지의 강의계획서에서 과목명, 과목코드, 강의시간, 강의실을 뽑아 DB로 만들고, 원하는 과목을 넣으면 가능한 시간표를 모두 만들어 줍니다. Java(JDBC, Servlet)와 MS Access.
- **e-mail 관리 프로그램** — 11기 선진욱, 15기 이동희, 15기 이지민

  여러 계정에 흩어진 메일을 한곳에서 확인하는 프로그램. Java-mail API.

## 2002년

- **Freedom Fighter Online (F.F. Online)** — 11기 김현웅, 11기 선진욱, 12기 조영대, 13기 최광호

  1998년 시크스퀘어에 출품한 슈팅 게임 Freedom Fighter의 온라인 버전. 사용자 간 대결에 롤플레잉 요소(레벨업, 아이템)를 더했습니다. Linux 서버, SQL Server 2000, VC++, DirectX.
- **EVE** — 13기 이창식, 15기 김태현

  DirectX 7.0 슈팅 게임. 스테이지 3개와 보스, 5단계 파워업. 키보드와 조이스틱 지원.
- **KNU 메신저** — 15기 서원경, 15기 백종복

  학교 소식과 동문 소식을 뉴스 형식으로 보여 주는 교내용 메신저. 여러 사람에게 쪽지, 그룹 전송, 다중 대화, 파일 멀티 전송. Linux, MySQL, MFC.

## 2003년

- **3D 큐빅** — 13기 이창식

  루빅 큐브 게임. 테마 추가, 시간 기록, 중간 저장을 지원합니다. DirectX 9.0, Visual C++ .NET.
- **위치 인지 시스템** — 15기 곽효석, 16기 이안석

  GPS 모듈을 단 PDA로 현재 위치와 그 장소의 정보를 받아 보는 시스템. 공대 5호관 근처에 가면 시크스퀘어 정보가, 식당 근처에 가면 메뉴가 뜹니다. Embedded Linux, Qt/Embedded, Linux + MySQL + PHP 서버.

  **시크스퀘어2003 테크노파크 단장상(소프트웨어 부문)**

## 2004년

- **자동 주차 시스템** — 12기 최성철

  주차장 위 카메라로 빈자리를 찾고, 네트워크로 차량에 움직임을 보내 자동으로 주차시키는 시스템.
- **Picture & Voice Chatter** — 12기 조영대, 18기 김경륜

  방 하나에 8명이 참여하는 화상·음성 채팅. 파일 교환 기능. Centralized P2P와 RTP.
- **음성 인식 강아지** — 15기 김태현, 18기 이수헌, 이승환, 최종문

  음성 명령을 알아듣고 움직이는 레고 강아지 로봇.
- **하늘구름** — 16기 이안석, 18기 박경렬

  PDA 같은 임베디드 환경을 위한 Hybrid P2P 프로그램. XML-RPC 기반 프로토콜, 파일 공유, 오디오·비디오 스트리밍, 메신저, NFS, 자체 동영상 플레이어(구름 Player). ARM 보드의 Embedded Linux, TinyX, GTK+.

  **시크스퀘어2004 동아리작품부문 최우수상**
- **3D 팩맨** — 13기 이창식

  팩맨을 360도 회전 시점의 3D로 다시 만들고 아이템을 더한 게임. Visual Studio .NET 2003, DirectX 9.0, 3D Studio Max.
- **사진 이야기** — 18기 김준호

  크기·밝기 조절, 자르기, 일괄 이름 바꾸기, 액자와 글자 넣기, EXIF 보기, FTP 전송, HTML 자동 생성을 지원하는 사진 관리 프로그램.

  **시크스퀘어2004 동아리작품부문 특별상**
