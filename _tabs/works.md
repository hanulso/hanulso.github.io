하늘소 회원들이 대회, 전시회, 동아리 사업으로 만든 작품입니다. 1997년 하늘소 작품전시회 책자, SEEK SQUARE 2000 책자, 2004~2008년 모바일-디스플레이 NURI 엑스포 디렉터리 책자, 2006년 홈페이지의 [하늘소작품](https://web.archive.org/web/20060303234125/http://hanulso.knu.ac.kr/project/project.php) 페이지를 옮기며 설명을 줄였습니다. 참여자는 당시 표기대로 기수와 이름을 적었습니다. 작품 화면은 옛 홈페이지 소스(2011년 무렵 작업 사본)에 남아 있던 그림과, 전시 책자 사진에서 잘라 낸 그림입니다. 책자는 [자료](/materials/)에서 넘겨 볼 수 있습니다.

> 이 목록은 2008년에서 멈춰 있습니다. 그 뒤의 작품이나 설명이 비어 있는 작품을 아시는 분은 [GitHub 이슈](https://github.com/hanulso/hanulso.github.io/issues)로 올려 주세요.

## 1997년 — 제11회 하늘소 작품전시회

1997년 11월 27~28일 공대 5호관 Invention hall에서 연 전시회 책자에 실린 회원 작품입니다.

- **연필** — 5기 임효상

  한글 문서 편집기. 윈도우의 트루타입 글꼴 대신 도스의 비트맵 글꼴을 써서 영문 윈도우에서도 한글을 쓸 수 있었고, 조합형과 완성형을 모두 지원했다.
- **Multi-Talk** — 3기 박미룡

  IP 멀티캐스트로 인터넷에 연결된 여러 컴퓨터가 한꺼번에 메시지를 주고받는 프로그램. Visual C++과 윈속 1.1로 만든 Windows 95, NT용.
- **Web Server** — 7기 문재철

  서버 상태를 실시간으로 볼 수 있는 웹 서버.
- **소리박사** — 5기 이준규

  사람의 음성을 실시간으로 인식하는 프로그램. 음성 파형과 주파수 스펙트럼을 보여 주고, LPC 켑스트럼 계수와 신경망으로 어떤 소리인지 알아냈다. 97 불사조 전자 작품전 출품작.
- **아들과 딸** — 5기 이준규

  두 사람의 사진을 넣으면 예상되는 자녀 얼굴을 합성해 주는 프로그램. 일본의 사진 합성 자판기에서 착안했다.
- **일급비밀** — 7기 김옥구

  인터넷 암호화 프로그램. 방화벽 기능을 갖췄다.
- **Web Timetable Maker** — 7기 김옥구

  듣고 싶은 과목을 고르면 가능한 시간표를 모두 만들어 주는 웹 프로그램. Personal Oracle 7.3을 쓴 3계층 구조로 만들었다. 97 불사조 전자 작품전 2위.
- **나룻배 (웹 브라우저)** — 9기 박준호

  HTML 1.0 기반 웹 브라우저. C++ 4.2로 문서 해석, 출력, 접속 부분을 만들었고 스크립트를 빼면 거의 모든 기능을 지원했다. 97 불사조 전자 작품전 출품작.
- **µpSim (8085 시뮬레이터)** — 9기 박동환

  학부 마이크로프로세서 실험에 쓰던 8085 실험 기구를 소프트웨어로 옮긴 시뮬레이터.
- **배달부** — 9기 김근우

  네트워크로 자료를 주고받는 전송 프로그램.
- **누리터 (Web BBS)** — 9기 정철규

  IIS와 SQL Server로 만든 웹 게시판.
- **외양간 지기** — 10기 조인영

  하늘소 회원과 그동안 모은 자료, 소스를 웹에서 데이터베이스로 관리하는 프로그램.
- **Muse (주문형 오디오)** — 10기 한혜영 (불새 김원기와 공동)

  인터넷 주문형 오디오 서비스. MP3 스트림을 실시간으로 보내고 받아 재생하며 정지, 재시작, 위치 이동을 지원했다. 동아리 불새가 전용 사이트를, 하늘소가 클라이언트와 서버를 맡은 공동 작품.
- **징검다리 (널 모뎀)** — 11기 (책자에 개발자 이름 대신 작품명이 인쇄됨)

  모뎀 없이 두 컴퓨터를 이어 문장과 파일을 주고받는 널 모뎀 프로그램. 풀다운 메뉴로 만들었다.
- **좋은 날 (바이오리듬)** — 11기 권동현

  생년월일과 알고 싶은 날을 넣으면 바이오리듬 그래프와 그날의 상태를 보여 주는 프로그램.
- **Cross Word** — 11기 선진욱

  9×9 칸 낱말 맞추기 게임. 도스용 한글 라이브러리로 만들었고 7단계까지 있다.
- **사주팔자** — 11기 김현웅

  생년월일로 사주팔자와 운세를 보고 프린터로 뽑을 수 있는 프로그램.
- **일기장** — 11기 이수준

  일기장과 주소록을 묶은 도스용 개인 정보 관리 프로그램.
- **네모네모 로직** — 11기 이장우

  신문과 잡지에 실리던 네모네모 로직 퍼즐을 옮긴 게임.
- **주소록** — 11기 신성은

  회원 주소를 관리하는 데이터베이스 프로그램. Windows MFC와 ODBC.
- **Chart Doctor (차트식 건강진단)** — 11기 이신덕

  잡지의 차트식 건강진단을 옮긴 프로그램. 예, 아니오 질문을 따라가면 마지막에 결과가 나온다.
- **Black Jack** — 11기 서승민, 이현태

  카드 게임 블랙잭. 게임이 끝나면 양쪽 카드를 볼 수 있다.
- **Final TETRIS** — 11기 전대곤

  Win32로 만든 윈도용 테트리스. 깔끔한 화면에 신경 썼다.
