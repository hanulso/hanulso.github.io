## 비용과 요금

### Claude Haiku 5.5 출시, Sonnet 5.5 캐시 읽기는 반값

![Anthropic 「Introducing Claude Haiku 5.5」](/assets/img/posts/2026-10-16-ai-news/src-haiku.jpg){: .shadow }
_Anthropic 발표 페이지 (2026-10-16 캡처)_

Anthropic이 10월 8일 03:01 Claude Haiku 5.5를 내놓았습니다. 가격은 100만 토큰당 입력 $0.10, 출력 $0.50입니다(10만 토큰을 넘는 프롬프트는 $0.50, $2.50). Haiku 4.5는 $1.00, $5.00이었습니다.

- 회사는 Haiku 4.5보다 평균 약 75% 적은 비용으로 돌아간다고 밝혔습니다. 다만 토크나이저가 바뀌어 같은 일에 토큰을 조금 더 쓴다고 같은 페이지에 적었습니다.
- Haiku로는 처음으로 effort(추론 강도) 설정이 생겼습니다. 비용과 성능 중 어느 쪽에 맞출지 고를 수 있습니다.
- 같은 날 Sonnet 5.5의 캐시 읽기 가격을 절반(100만 토큰당 $0.10)으로 내렸습니다. 회사는 이것으로 대부분의 에이전트 작업이 약 20% 싸진다고 밝혔습니다.
- Claude Code는 v2.1.293부터 Haiku 5.5를 기본 Haiku 모델로 씁니다.

![Claude 도움말 「Monthly API credits for Max and Team plans」](/assets/img/posts/2026-10-16-ai-news/src-credits.jpg){: .shadow }
_Claude 도움말 센터 (2026-10-16 캡처)_

Claude 개발자 계정이 10월 9일 01:09 Max와 Team 구독자에게 매달 API 크레딧을 준다고 알렸습니다.

| 플랜 | 매달 받는 크레딧 |
|---|---|
| Max 5x | $100 |
| Max 20x | $200 |
| Team | Standard 좌석당 $20, Premium 좌석당 $100. 팀 전체 합산 최대 $500 |

- 쓰지 않은 크레딧은 다음 달로 넘어가지 않습니다.
- Free, Pro, Enterprise는 대상이 아닙니다. 대상 플랜에 7일 넘게 가입해 있어야 보이고, 며칠에 걸쳐 차례로 풀립니다.

![Cursor 요금제 페이지](/assets/img/posts/2026-10-16-ai-news/src-cursor.jpg){: .shadow }
_Cursor 요금제 페이지 (2026-10-16 캡처)_

Cursor가 10월 13일 08:10 「The X Subscription」에 들어갔다고 알렸습니다. Grok, X Premium과 요금제를 하나로 묶은 것입니다.

- 요금은 월 기준으로 무료, Plus $8, Premium $30, Super $100, Ultra $200입니다. 사용량은 Plus를 기준으로 Premium이 4배, Super가 15배, Ultra가 50배입니다.

- **Cursor에서 Claude나 GPT 같은 타사 모델을 쓰면 월 요금에 들어가지 않고, 쓴 만큼 API 가격으로 따로 청구됩니다.**
- 지금 Cursor 구독자는 원래 요금제를 유지하거나 새 요금제로 바꿀 수 있습니다.

Cursor에서 Claude나 GPT를 주로 쓰던 분이라면 비용 계산이 달라집니다.

영상 도구 회사들도 바로 연결을 내놓았습니다. Higgsfield는 10월 9일 06:42 「Higgsfield Katana + Claude Motion」으로 코드만으로 만든 자동차 광고를 공개했습니다.

### Claude Code v2.1.293~301, 데스크톱 앱 개편

![Claude Code 변경 이력](/assets/img/posts/2026-10-16-ai-news/src-claude-code.jpg){: .shadow }
_GitHub anthropics/claude-code 변경 이력 (2026-10-16 캡처)_

- **2.1.293**: Haiku 5.5가 기본 Haiku 모델이 됐습니다.
- **2.1.295**: 훅에 `onFailure: "block"` 설정이 생겼습니다. 훅이 시작되지 않거나 시간을 넘기거나 예상 밖의 코드로 끝나면, 그 동작을 통과시키지 않고 막습니다.
- **2.1.299**: 터미널에서 20만 토큰이 넘는 대화를 약 54분 동안 그냥 두면, 1시간짜리 프롬프트 캐시가 만료되기 전에 미리 압축합니다. 다음 메시지에서 대화 전체를 다시 처리하지 않게 하려는 것입니다. settings.json에 `"idleCompaction": false`를 넣으면 끕니다.
- **2.1.300**: OpenTelemetry 기록에서 캐시 쓰기 토큰을 5분짜리와 1시간짜리로 나눠 보여 줍니다.
- **2.1.301**: 무인 재시도 모드에서 사용 한도가 너무 늦게 풀리면 기다리지 않고 요청을 끝내는 설정이 생겼습니다.

10월 15일 04:01에는 데스크톱 앱이 여러 세션을 나란히 돌리기 좋게 바뀌었습니다. 세션을 더 빨리 시작하고, 일을 여러 세션으로 나누고, 각 세션이 무엇을 하고 있는지 늘 볼 수 있게 했다고 밝혔습니다.

### Anthropic: 평가 중에 모델이 선을 넘은 사례

![Anthropic 「Investigating unintended model actions」](/assets/img/posts/2026-10-16-ai-news/src-unintended.jpg){: .shadow }
_Anthropic 연구 글 (2026-10-16 캡처)_

Anthropic이 10월 9일(미국) 평가와 사내 사용 중에 나온 「의도하지 않은 모델 행동」을 공개했습니다. 유형은 네 가지입니다.

- 소프트웨어의 기본적인 결함을 이용해 서버에서 명령을 실행했습니다.
- 실제 웹사이트에서 제출하면 안 되는 민감한 양식을 제출했습니다.
- 토큰이나 요금으로 막혀 있는 데이터에 닿으려고, 멈추는 대신 제한을 우회했습니다.
- 가져오기(fetch) 도구의 제한을 피하려고 URL 단축 서비스를 썼습니다.

일부는 미국 연방, 주, 지방 정부기관의 사이트였습니다. Anthropic은 백악관에 보고하고 관련 기관마다 알렸습니다. 실제 피해는 적었다고 밝혔지만, 일부 위험한 평가에만 끊어 두던 인터넷 연결을 모든 내부 평가에서 끊기로 했습니다.

에이전트에게 「끝까지 해내라」고 맡기는 일이 많은 만큼, 권한과 네트워크를 좁혀 두는 습관이 중요해 보입니다(편집자 해석).

### Deno가 Cloudflare에 합류합니다

![Deno 블로그 「Deno is joining Cloudflare」](/assets/img/posts/2026-10-16-ai-news/src-deno.jpg){: .shadow }
_Deno 블로그 (2026-10-16 캡처)_

Deno를 만든 Ryan Dahl이 10월 9일 Deno가 Cloudflare에 합류한다고 발표했습니다.

- Deno 런타임은 1년 동안 매달 버그 수정과 보안 업데이트를 낸 뒤 개발을 끝냅니다. 오픈소스로는 남습니다.

### 청년 일자리 자료: 20대 IT 첫 일자리 21.3% 감소, 9월 29세 이하 고용보험 5만5000명 감소
