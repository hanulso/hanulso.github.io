## 비용과 사용 한도

### Codex는 캐시를 계속 유지하고, Claude Code는 재개 비용을 경고합니다

![OpenAI 프롬프트 캐싱 문서](/assets/img/posts/2026-10-23-ai-news/src-cache.jpg){: .shadow }
_OpenAI API 문서 (2026-10-23 캡처)_

- **OpenAI API에 12시간 캐시가 생겼습니다.** 기본 30분 캐시는 쓰기 비용이 일반 입력의 1.25배이고, 새로 생긴 12시간 캐시는 2.5배입니다. 읽기 비용은 두 가지 모두 일반 입력의 0.1배이고, GPT-6.1 Sol은 0.05배입니다.
- **Codex는 캐시를 계속 유지합니다.** Codex 총괄 Tibo Sottiaux는 10월 21일 10:10 「28일 약속」 16일차로, Codex와 Work에 로그인한 사용자의 캐시를 계속 유지한다고 밝혔습니다. 몇 시간 뒤 옛 대화로 돌아와도 손해가 없고, 캐시 적중이 보장된다고 합니다.
- **Claude Code는 반대로 경고를 넣었습니다.** v2.1.304부터 Pro와 Max 플랜에서 오래 쉰 대화를 다시 열면 5시간 사용 한도를 꽤 쓴다는 경고를 보여 줍니다. 그대로 이어 가거나, 새 대화를 열고 필요할 때 이전 대화를 찾아보게 할 수 있습니다.

같은 「오래 쉰 대화」를 두고 두 도구가 다르게 움직인 주였습니다. Claude Code에서는 쉬었다 돌아올 때 새 대화로 시작하는 편이 한도를 아끼는 방법이 됩니다(편집자 해석).

### PHP 치명 취약점 두 건, AI로 찾았고 국내 패치는 아직 4% 남짓

![Google Cloud 블로그 「Responding to core PHP vulnerabilities」](/assets/img/posts/2026-10-23-ai-news/src-php.jpg){: .shadow }
_Google Cloud 블로그 (2026-10-23 캡처)_

PHP 언어 자체에서 인증 없이 원격 코드 실행과 메모리 노출이 가능한 취약점 두 건(CVE-2026-109618, CVE-2026-109619)이 10월 21일 공개됐습니다.

- 심각도(CVSS)는 9.2이고, PHP 5.4부터 8.5.11까지 모두 영향을 받습니다.
- 패치 버전은 8.5.12, 8.4.27, 8.3.36, 8.2.35입니다. **8.1 이하는 지원이 끝나 패치가 나오지 않습니다.**
- OpenAI는 자사 모델이 연구자들의 발견을 도왔다고 밝혔고, Google Cloud는 Wiz가 여러 모델을 함께 써서 찾았다고 적었습니다.
- AWS는 공개 나흘 전인 10월 17일에 이미 악용 시도를 관측했다고 밝혔습니다.
- 보안뉴스와 에스케어가 10월 23일 11시 기준으로 조사해 보니, 패치 대상인 국내 PHP 8.2~8.5 서버 약 5,500대 중 수정판을 쓰는 곳은 약 3.8%(210여 대)였습니다.

PHP로 돌아가는 서버나 동아리 프로젝트가 있다면 바로 올려야 합니다.

### 에이전트가 감시 장치를 끈 사례

![METR 「Red-Teaming OpenAI's Internal Agent Monitoring Systems」](/assets/img/posts/2026-10-23-ai-news/src-metr.jpg){: .shadow }
_METR 블로그 (2026-10-23 캡처)_

- METR과 Redwood Research 직원이 올여름 3주 동안 OpenAI의 내부 감시 체계를 점검한 결과도 10월 22일 공개됐습니다. Codex 에이전트가 이론상 샌드박스와 자동 검토(Auto-Review)를 우회할 수 있는 경로, 최근 행동 수백 건을 감시에서 빠지게 하는 방법을 찾았습니다. OpenAI는 모두 고쳤다고 밝혔고, METR은 그 주장을 검증하지 않았다고 적었습니다.

auto mode처럼 에이전트에게 더 맡기는 흐름일수록, 에이전트가 만든 변경을 끝까지 읽는 일이 중요해 보입니다(편집자 해석).

## 개발 도구

### Claude API 새 버전 2026-10-21: temperature를 보내면 오류

![Claude Platform 문서 「Migrating to API version 2026-10-21」](/assets/img/posts/2026-10-23-ai-news/src-api-version.jpg){: .shadow }
_Claude Platform 문서 (2026-10-23 캡처)_

Claude API에 2023-06-01 이후 처음으로 새 API 버전 2026-10-21이 나왔습니다. 새 버전에서는 Messages API에 `temperature`, `top_p`, `top_k`를 보내면 기본값이어도 400 오류가 납니다. 새 SDK의 기본값이 이 버전이라, SDK만 올려도 코드가 깨질 수 있습니다. Claude Code 2.1.307에는 코드를 새 버전으로 옮겨 주는 `/claude-api api-version` 명령이 들어갔습니다.

### Claude Code v2.1.302~309

![Claude Code 변경 이력](/assets/img/posts/2026-10-23-ai-news/src-claude-code.jpg){: .shadow }
_GitHub anthropics/claude-code 변경 이력 (2026-10-23 캡처)_
