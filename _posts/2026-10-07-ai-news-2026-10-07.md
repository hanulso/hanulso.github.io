### Codex: 28일 동안 매일 하나씩 고치거나, 못 하면 사용량 초기화

![OpenAI 개발자 커뮤니티 「Free Auto Review: Day 2 of 28 days」 글](/assets/img/posts/2026-10-07-ai-news/src-codex.jpg){: .shadow }
_OpenAI 개발자 커뮤니티 (2026-10-07 캡처)_

OpenAI Codex 총괄 Tibo Sottiaux가 10월 5일 05:33 X에 약속을 올렸습니다. 앞으로 28일 동안 날마다 대부분의 Codex·Work 사용자에게 분명한 개선을 하나씩 내놓고, 못 하는 날에는 사용량을 전부 초기화하겠다는 내용입니다.

- **1일차(10월 6일 02:20)**: GPT-6 Astra와 GPT-6.1 Sol의 기본 속도를 약 50% 높였습니다. 구독으로 쓰는 모든 OpenAI 제품과, 「Sign in with ChatGPT」로 로그인하는 OpenCode·Pi·Amp·Devin 같은 협력사 도구에도 적용됩니다.

- **초기화(10월 7일 12:35)**: 네 가지를 내놓았지만, 커뮤니티 투표 결과에 따라 사용량 초기화도 실행했다고 밝혔습니다.

매일 Codex를 쓴다면 속도와 남은 사용량이 바로 달라지는 소식입니다.

### Claude Code v2.1.289~292

![Claude Code CHANGELOG의 2.1.292 항목](/assets/img/posts/2026-10-07-ai-news/src-claude-code.jpg){: .shadow }
_Claude Code CHANGELOG (2026-10-07 캡처)_

10월 4일부터 7일까지 Claude Code가 네 번 업데이트됐습니다(npm 게시 기준 v2.1.289 10월 4일, v2.1.290·291 10월 6일, v2.1.292 10월 7일). 매일 쓰면서 느낄 만한 것만 골랐습니다.

- **서브에이전트 노력 수준 지정(2.1.292)**: Agent 도구에 `effort` 파라미터가 생겨, 서브에이전트를 원하는 노력 수준으로 실행할 수 있습니다.
- **웹 검색 한도가 충전식으로(2.1.290)**: 대화형 세션의 WebSearch가 200번 쓰면 끝나던 방식에서 시간당 100번씩 다시 채워지는 방식으로 바뀌었습니다.
- **프록시 버그 수정(2.1.292)**: `HTTPS_PROXY`를 설정하면 Claude Code 자체 요청에서 `NO_PROXY`가 무시되던 문제를 고쳤습니다.
- **로컬 MCP 프로토콜(2.1.292)**: 로컬(stdio) MCP 서버와 기본으로 프로토콜 2026-07-28을 협상합니다. `MCP_PROTOCOL_NEGOTIATION=legacy`로 끌 수 있습니다.
- **플러그인 설치 한 번에(2.1.292)**: `claude plugin install --marketplace <source>`가 마켓플레이스 추가와 설치를 한 번에 합니다.
- **`/code-review`(2.1.290)**: medium 단계에서 Opus 5.5·Sonnet 5.5로도 정리 항목과 CLAUDE.md 관례 위반을 함께 보고합니다.

### GitHub 스택형 PR 정식 출시

![GitHub 변경 이력 「Stacked pull requests generally available」](/assets/img/posts/2026-10-07-ai-news/src-stacked-pr.jpg){: .shadow }
_GitHub 변경 이력 (2026-10-07 캡처)_

GitHub이 10월 6일(미국) **스택형 PR(stacked pull requests)**을 정식으로 내놓았습니다. 큰 변경을 작은 PR 여러 개로 쪼개 따로 리뷰하고, 함께 머지할 수 있습니다. 모든 github.com 플랜에서 쓸 수 있습니다.

- GitHub CLI 확장 `gh stack`이 Git worktree를 지원합니다.
- 스택을 재배치(rebase)해도 커밋 서명과 원래 작성자가 유지되고, 이미 받은 승인도 남습니다.
- GitHub은 프리뷰 기간에 스택을 쓴 저장소의 머지된 코드가 비슷한 저장소보다 9% 늘었다고 밝혔습니다.

에이전트가 만든 큰 변경을 리뷰하기 좋은 크기로 나누는 데 바로 쓸 수 있습니다.

![Reflection 「Introducing Beam」 글](/assets/img/posts/2026-10-07-ai-news/src-beam.jpg){: .shadow }
_Reflection 블로그 (2026-10-07 캡처)_

미국 Reflection AI가 10월 5일(미국) 첫 오픈 웨이트 모델 **Beam**을 공개했습니다.

- 전체 5010억 파라미터 가운데 230억 개를 쓰는 MoE 모델로, 코딩·추론·에이전트 작업을 겨냥했습니다.

### AI안전연구소: 에이전트 공격을 완전히 막는 모델은 없었다

![이데일리 「AI 해킹 막을 모델 없다…잘못된 정보 심자 91.2%가 공격자 뜻대로」](/assets/img/posts/2026-10-07-ai-news/src-agent-attack.jpg){: .shadow }
_이데일리 (2026-10-07 캡처)_

10월 6일 국정감사에 맞춰 김우영 의원실이 받은 AI안전연구소의 자율형 AI 에이전트 평가 결과가 보도됐습니다(뉴시스·이데일리).

- **프롬프트 주입**: 업무 지시처럼 꾸민 악성 명령에 대한 모델별 평균 방어율은 53.3~93.9%였습니다. 모든 모델에서 공격이 성공한 사례가 있었습니다.
- **내부 정보 탈취·조작**: 평가 중 인증키, 시스템 설정값, 개인정보가 빠져나간 사례가 나왔습니다.
- **장기 메모리 공격**: 외부에서 편향된 정보를 에이전트의 장기 메모리에 저장하게 하자, 7개 모델의 평균 공격자 의도 일치율(AAR)이 91.2%였습니다. 한 번 틀린 답을 내는 데서 끝나지 않고 이후 판단까지 계속 비틀 수 있다는 뜻입니다.
- 제출 자료에는 이런 공격을 「완전 차단할 수 있는 LLM 모델은 확인되지 않은 상황」이라고 적혀 있습니다.

코딩 에이전트에 파일 읽기 권한과 메모리를 맡기고 있다면, 아래 「써 볼 만한 것」의 Agent Guard처럼 비밀정보가 에이전트 컨텍스트에 들어가지 않게 막는 장치를 함께 두는 것이 좋겠습니다.

### SW 신입 채용 반토막, 부총리 「기회가 줄어드는 것은 사실인 것 같다」

![머니투데이 「ICT 신입채용 3년새 48%↓」 기사](/assets/img/posts/2026-10-07-ai-news/src-sw-hiring.jpg){: .shadow }
_머니투데이 (2026-10-07 캡처)_

이훈기 의원이 10월 1일 분석한 ICT 채용 자료가 10월 6일 국정감사 질의로 이어졌습니다(주간한국·머니투데이).

- ICT 신입 채용은 2022년 9만 5116명에서 2025년 4만 8669명으로 48.8% 줄었습니다.
- 소프트웨어 개발·제작업은 2024년에서 2025년 사이 전체 채용이 4.7% 줄었는데, 신입은 3만 4022명에서 1만 7912명으로 **47.4%** 줄고 경력은 1만 951명에서 2만 4941명으로 **127.8%** 늘었습니다. 2025년 경력직 비중은 58.2%입니다.
- 배경훈 부총리는 「초기에 신입사원으로 채용될 수 있는 기회가 줄어드는 것은 사실인 것 같다」고 답했고, 내년에 청년 일자리 관점에서 중요한 발표를 하겠다고 했습니다.

일부 기사에는 소프트웨어 신입 감소율이 「4.7%」로 나오는데, 4.7%는 전체 채용 감소율이고 신입은 47.4%입니다.

### 긱뉴스 Show GN: 국내 개발자가 만든 코딩 에이전트 도구 셋

![긱뉴스 「Show GN: Agent Guard」 글](/assets/img/posts/2026-10-07-ai-news/src-agent-guard.jpg){: .shadow }
_긱뉴스 (2026-10-07 캡처)_

10월 6일 긱뉴스 Show GN에 Claude Code·Codex를 쓰는 개발자가 직접 만든 도구가 셋 올라왔습니다. 모두 MIT 라이선스이고 작은 개인 프로젝트입니다(GitHub 스타 31·3·7개, 10월 7일 19시 기준).

- **Agent Guard**: Claude Code·Codex가 `.env` 같은 민감 파일을 읽기 전에 막고, 도구 출력에 섞인 비밀정보를 `[REDACTED]`로 바꾸고, gitleaks로 변경 파일과 커밋을 검사합니다. 처리는 로컬에서 합니다.
- **Agent HUD**: Claude Code 플러그인과 스킬을 프로젝트별로 켜고 끄는 macOS 대시보드입니다. 세션마다 읽히는 스킬 수와 토큰을 보여 줍니다.
- **Illithid**: Claude Code·Codex·OpenCode·Gemini CLI·GitHub Copilot·Grok CLI의 룰, 스킬, 서브에이전트, MCP 설정을 한 곳에서 편집해 모든 도구에 맞춰 주는 macOS 앱입니다.
