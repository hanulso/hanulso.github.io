## 코딩 도구

### Claude Code에 Mods가 생겼습니다

![Anthropic 「Customize Claude Code with mods in TypeScript」 글](/assets/img/posts/2026-10-03-ai-news/src-mods.jpg){: .shadow }
_Claude 블로그 (2026-10-03 캡처)_

Anthropic이 10월 1일(미국) Claude Code에 **Mods**를 내놓았습니다. 몇 줄짜리 TypeScript로 Claude Code의 동작과 화면을 바꾸는 확장입니다. 플러그인에 담아 나눌 수 있고, CLI와 데스크톱 앱에서 동작합니다.

- Claude Code의 기본 기능 일부도 이제 mod입니다. 예를 들어 `/diff`는 끄거나 내가 만든 것으로 바꿀 수 있습니다.
- **샌드박스가 없습니다.** mod는 Claude Code와 같은 권한으로 내 컴퓨터에서 돌아가니, 믿을 수 있는 곳의 mod만 깔라고 안내합니다.
- Team·Enterprise 요금제와 관리 설정이 있는 컴퓨터에서는 `sec-default`라는 기본 mod가 먼저 실행돼, 사용자가 깐 mod의 위험한 동작을 막습니다.

같은 주 Claude Code에는 원격으로 쓸 때 필요한 수정이 여럿 들어갔습니다.

- v2.1.285(9월 30일): `claude --desktop`으로 지금 폴더를 데스크톱 앱에서 엽니다.
- v2.1.287~288(10월 2~3일): Remote Control이 몇 분씩 메시지를 못 받던 문제, Mac이 잠자기에 들어가면 `claude remote-control` 세션이 멈추던 문제 등을 고쳤습니다.
- v2.1.288(10월 3일): Ctrl+C로 지운 프롬프트를 빈 입력칸에서 ↑로 되살릴 수 있습니다. 권한 확인 없이 도는 설정에서 `bash -c` 안의 위험한 `rm`이 그대로 실행되던 문제도 고쳤습니다.

### OpenAI DevDay: GPT-6.1 Sol

![GitHub 변경 이력 「GPT-6.1 Sol in GitHub Copilot」](/assets/img/posts/2026-10-03-ai-news/src-gpt61.jpg){: .shadow }
_GitHub 변경 이력 (2026-10-03 캡처)_

OpenAI는 9월 29일(미국) DevDay에서 **GPT-6.1 Sol**을 내놓았습니다. 9월 22일에 나온 GPT-6 Sol의 후속입니다.

- OpenAI 변경 이력에는 「GPT-6 Astra보다 낮은 비용으로 복잡한 코딩과 전문 업무를 하는 모델」이라고 적혀 있습니다.
- API 가격은 입력 272K 토큰 이하 기준으로 100만 토큰당 입력 $2, 캐시 입력 $0.10, 캐시 쓰기 $2.50, 출력 $10입니다.
- 서브에이전트에 일을 나눠 맡기는 멀티 에이전트 기능이 베타로 들어갔습니다.
- Codex와 ChatGPT Work에서도 쓸 수 있고, GitHub Copilot에서도 같은 날 정식 제공을 시작했습니다(Pro+·Max·Business·Enterprise).

### OpenAI dots: 늘 켜져 있는 에이전트

![OpenAI 「Meet dots」 문서](/assets/img/posts/2026-10-03-ai-news/src-dots.jpg){: .shadow }
_ChatGPT Learn 「Meet dots」 문서 (2026-10-03 캡처)_

같은 날 나온 **dots**는 늘 켜져 있는 개인 에이전트입니다.

- GPT-6 Astra 기반이고, 클라우드에 자기 컴퓨터와 브라우저를 갖고 있어 내 컴퓨터가 꺼져 있어도 일을 이어 갑니다.
- ChatGPT, Slack, Teams, 전화로 같은 dot과 이야기할 수 있습니다. 데스크톱 앱에서 연결하면 내 컴퓨터의 파일과 코드도 쓸 수 있습니다.
- 대상은 Pro 100·200·500(만 18세 이상, 유럽경제지역·영국·스위스 제외), Business Premium, Enterprise입니다. Enterprise는 관리자가 켜야 하고, 차례로 배포 중이라 대상이어도 바로 안 보일 수 있습니다.
- dot과의 대화는 ChatGPT 사용 한도에 들어가지 않습니다. dot이 Work나 Codex에서 시작한 작업은 그쪽 한도를 씁니다.

### ChatGPT Space: 함께 편집하는 문서 공간

![OpenAI 「ChatGPT Space」 문서](/assets/img/posts/2026-10-03-ai-news/src-space.jpg){: .shadow }
_ChatGPT Learn 「ChatGPT Space」 문서 (2026-10-03 캡처)_

문서·PPT를 AI로 만드는 도구에 OpenAI 쪽 선택지가 하나 더 생겼습니다. **ChatGPT Space**는 페이지와 파일을 한곳에 모아 ChatGPT와 함께 쓰고, 다른 사람을 불러 같이 편집하는 공간입니다.

- 페이지(문서) 외에 스프레드시트와 프레젠테이션도 ChatGPT와 함께 만들고 고칠 수 있다고 문서에 적혀 있습니다.
- Google Drive 같은 연결 앱의 파일을 끌어와 요약·비교에 쓸 수 있습니다. 연결한 파일은 원래 권한을 그대로 따릅니다.

### Gemini 4 Argon은 아직 못 씁니다

![Google 「Introducing Gemini 4 Argon」 글](/assets/img/posts/2026-10-03-ai-news/src-argon.jpg){: .shadow }
_Google 블로그 (2026-10-03 캡처)_

**Gemini 4 Argon**은 9월 30일(미국) 발표됐지만, 아직 일반 사용자는 쓸 수 없습니다.

- 지금은 사이버 방어 담당자를 위한 Fairwind 프로그램에만 풀었습니다. 다음 차례는 유료 API 고객과 Google AI Ultra 구독자인데, 날짜는 밝히지 않았습니다.
- 도입가는 100만 토큰당 입력 $2, 출력 $10이고, 도입 기간이 끝나면 $4, $20입니다.
- 출력 한도를 64K에서 1M 토큰으로 늘렸습니다.
- Google은 DeepSWE v1.1에서 77.9%로 최고 기록을 세웠다고 밝혔습니다.

### GitHub Copilot: 컴퓨터 사용, HydraFusion, Opus 4.7 종료

![GitHub 변경 이력 「GitHub Copilot can now interact with desktop apps with computer use」](/assets/img/posts/2026-10-03-ai-news/src-copilot.jpg){: .shadow }
_GitHub 변경 이력 (2026-10-03 캡처)_

- **컴퓨터 사용(10월 1일, 공개 프리뷰):** Copilot CLI와 Copilot 앱(macOS·Windows)이 데스크톱 앱을 직접 조작합니다. CLI에서는 `/computer on`으로 켜고, 앱을 조작하기 전에 승인을 받습니다.
- **HydraFusion(9월 30일, 리서치 프리뷰):** 모델 목록에 하나로 보이지만, 작업에 따라 여러 모델을 세 방식 중 하나로 씁니다. 한 모델이 바로 풀거나(Single), 가벼운 모델이 초안을 쓰고 기준에 못 미치면 강한 모델로 넘기거나(Cascade), 다른 계열 모델이 초안을 검토한 뒤 한 번 고칩니다(Critique). VS Code 1.140 이상과 Copilot 앱에서 쓸 수 있습니다.
- **모델 지원 종료(10월 2일):** Claude Opus 4.7은 Opus 5.5로, Gemini 3.5·3.6 Flash는 3.8 Flash로, Kimi K2.7 Code는 K3로 바꾸라고 안내했습니다.

- AI중심대학은 신규 3곳과 SW중심대학에서 전환한 15곳입니다. 대학마다 최장 8년 동안 해마다 30억 원을 지원합니다.

경북대가 18곳에 들어 있는지는 이 기사로는 확인하지 못했습니다.

### 독파모는 계속됩니다

### herdr web ui: 폰에서 코딩 에이전트 다루기

![긱뉴스 Show GN 글 화면](/assets/img/posts/2026-10-03-ai-news/src-herdr.jpg){: .shadow }
_긱뉴스 Show GN (2026-10-03 캡처)_

코딩 에이전트를 서버에 두고 원격으로 쓰는 분이라면 볼 만한 도구입니다. 터미널 작업 공간 도구 herdr를 폰과 브라우저에서 채팅처럼 쓰는 웹 UI(PWA)입니다.

- 채팅 화면에서 승인과 질문에 바로 답하고, 파일을 올리고 볼 수 있습니다.
- 에이전트가 입력을 기다리거나 일을 끝내면 폰으로 푸시 알림이 옵니다.
- 폰에 앱으로 설치해 푸시를 받으려면 HTTPS가 필요하고, 작성자가 아직 베타라고 밝혔습니다.
